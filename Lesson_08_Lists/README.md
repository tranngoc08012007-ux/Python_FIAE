## 🎯 Objective
- Learn list operations: indexing, slicing, append, remove, pop
- Understand sorting and reversing lists
- Master list comprehension for transforming and filtering data
- Distinguish between `.append()` and `.extend()`

## 📚 Concepts Covered
- List basics (indexing, slicing)
- List modification (`append()`, `remove()`, `pop()`)
- Sorting & reversing (`sorted()`, `reversed()`, `.sort()`, `.reverse()`)

- `.append()` vs `.extend()`

## ✅ Key Takeaways
- List comprehension provides a concise way to transform and filter data.
- `sorted()`/`reversed()` return new objects, while `.sort()`/`.reverse()` modify the original list.
- `.append()` adds one element; `.extend()` adds multiple elements individually.
- Lists are one of the most important Python data structures and are widely used in real-world applications.
